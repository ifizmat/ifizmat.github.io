Оформление отчета. Подготовка к защите

Список документов к отчету по практике:
1. Рукописный дневник практики в тетради с распечатанным титульным листом. 
2. Распечатанный отчет по практике с титульным листом, 
оформленный по ГОСТ. Текст на одной стороне каждого листа.  
3. Распечатанная презентация, по 4 слайда на одном листе. 
4. Текст защиты с номерами и миниатюрами слайдов. 
5. Созданные на практике документы в электронном виде 
в общедоступной папке на Google Диске и в репозиториях 
GitFlic, GitVerse, GitHub, GitLab, ссылка на папку должна быть 
в отчете и на главной странице своего сайта.

Требования к структуре и оформлению отчета по учебной практике

  1. Титульный лист
  2. Содержание
    Оформление: список заголовков с номерами страниц.
  3. Индивидуальное задание.
  4. Общие задачи.
  5. Введение
    Содержание: постановка целей и задач практики в соответствии с заданием практики.
  6. Теоретические основы решения индивидуального задания.
    • Определения терминов предметной области
    • Формулы с пояснениями величин и указанием единиц измерения
    • Графики, чертежи, схемы
    • Скриншоты с примерами ПО
  7. Практическая часть индивидуального задания
    • Алгоритм решения задачи
    • Описание применяющегося для решения задачи ПО
    • Примеры расчетов по формулам
    • Скриншоты с результатами решения задачи
  8. Выполнение общих заданий
    Оформление: отдельный заголовок для каждого вида задач.
    • Алгоритм решения задачи
    • Описание применяющегося для решения задачи ПО
    • Примеры расчетов по формулам
    • Скриншоты с результатами решения задачи
  9. Выводы по практике
    Содержание: результаты, полученные при выполнении индивидуального и общих заданий, самооценка результатов, возможные перспективы совершенствования решений каждой из задач.
  10. Приложения
    • Презентация, 2 страницы по 4 слайда на странице
    • Текст защиты с номерами и миниатюрами слайдов.
