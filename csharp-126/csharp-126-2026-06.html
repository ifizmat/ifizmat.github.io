6.1. Основные компоненты (элементы управления) интегрированной среды разработки

Интегрированная среда разработки Visual Studio предоставляет программисту набор 
визуальных элементов управления для создания пользовательского интерфейса. 
Компоненты располагаются на панели Toolbox (Панель элементов) Ctrl+Alt+X
и делятся на категории по функциональному назначению.

Пример 6.1. Создание главного меню 
с помощью компонета MenuStrip.

На панели компонентов элемент MenuStrip 
находится в разделе Menus & Toolbars.
Среди основных операций с этим компонентом, 
которые доступны при нажатии на кнопку 
в правом верхнем углу, находится пункт 
Edit Items..., знак "..." означает, 
что при выборе пункта открывается диалоговое 
окно "Item Collections Editor". 

В этом окне можно удалить лишние пункты, 
добавить необходимые, изменить их параметры.

При выделении в этом окне основного пункта
меню в соседней панели открывается список 
его свойств.
Через свойство DropDownItems получают 
доступ к подпунктам меню, например, 
у главного пункта File - это подпункты: 
New, Open, Exit, Save, Save As с подписанными 
"горячими клавишами".

В качестве подпунктов можно добавить элементы
MenuItem, ComboBox, TextBox и разделительную 
черту SeparatorItems.

контейнеры,

например Click для кнопки или TextChanged для текстового поля.

5.2. Состав компонентов

Компоненты среды разработки классифицируются по группам.

Группа Common Controls включает базовые элементы интерфейса. 
Button представляет собой кнопку для инициирования действий. 
Label используется для отображения статического текста. 
TextBox позволяет пользователю вводить и редактировать однострочный 
или многострочный текст. 
CheckBox предоставляет возможность выбора одного или нескольких вариантов. 
RadioButton обеспечивает выбор единственного варианта из группы. 
ComboBox объединяет поле ввода и выпадающий список. 
ListBox отображает список элементов для выбора. 
PictureBox служит для вывода графических изображений.

Группа Containers предназначена для организации расположения элементов. 
Panel является универсальным контейнером для группировки элементов управления. 
GroupBox добавляет рамку с заголовком для логического разделения интерфейса. 
TabControl реализует интерфейс с вкладками для компактного размещения контента. 
FlowLayoutPanel и TableLayoutPanel обеспечивают автоматическое упорядочивание 
элементов по потоку или сетке.

Группа Menus & Toolbars содержит элементы навигации. 
MenuStrip создает главное меню приложения. 
ToolStrip позволяет размещать кнопки, метки и другие элементы на инструментальной панели. 
StatusStrip отображает информационную строку состояния в нижней части формы.

Группа Data включает компоненты для работы с данными. 
DataGridView предоставляет табличное представление данных с возможностями сортировки 
и редактирования. 
BindingSource обеспечивает связь между элементами управления и источниками данных.

Группа Components содержит небезвизуальные компоненты. 
Timer генерирует события через заданные интервалы времени. 
OpenFileDialog и SaveFileDialog реализуют стандартные диалоги работы с файлами. 
BackgroundWorker выполняет операции в фоновом потоке без блокировки интерфейса.

5.3. Назначение компонентов

Назначение компонентов определяется решаемыми задачами пользовательского интерфейса.

Элементы ввода данных обеспечивают взаимодействие пользователя с программой. 
TextBox принимает текстовую информацию, ComboBox и ListBox позволяют выбирать 
значения из предопределенного набора, NumericUpDown ограничивает ввод числовым 
диапазоном, DateTimePicker упрощает выбор даты и времени.

Элементы управления потоком выполнения инициируют действия. 
Button запускает обработчики событий, LinkButton открывает веб-ресурсы, 
MenuStrip и ToolStrip предоставляют доступ к командам приложения 
через иерархическое меню или панель инструментов.

Элементы отображения информации выводят результаты работы программы. 
Label показывает статические подписки и динамические сообщения, 
PictureBox отображает изображения, RichTextBox поддерживает форматированный текст, 
DataGridView представляет данные в табличном виде.

Элементы группировки и навигации организуют пространство формы. 
GroupBox и Panel визуально объединяют связанные элементы, 
TabControl разделяет контент по вкладкам, 
SplitContainer позволяет пользователю изменять пропорции областей интерфейса.

Служебные компоненты расширяют функциональность без визуального представления. 
Timer автоматизирует периодические операции, диалоговые компоненты 
обеспечивают стандартный интерфейс выбора файлов и настроек, 
компоненты работы с данными упрощают связь интерфейса с базами данных.

        {'#',' ',' ',' ','#','#','#','#','#',' ',' ','#','#','#','#','#','#'},
        {'#',' ',' ',' ',' ',' ',' ',' ',' ',' ',' ',' ',' ',' ',' ',' ','#'},
        {'#',' ',' ',' ',' ',' ',' ',' ',' ',' ',' ',' ',' ',' ',' ','X','#'},
        {'#','#',' ','#','#','#','#','#','#','#','#','#','#','#','#','#','#'}
    };
    int userX = 6, userY = 6;
    char[] bag = new char[1];
    while (true) {
        Console.SetCursorPosition(0, 0);
        for (int i = 0; i < map.GetLength(0); i++) {
            for (int j = 0; j < map.GetLength(1); j++) {
                Console.Write(map[i,j]);
            }
            Console.WriteLine();
        }
        Console.SetCursorPosition(0, 30);
        Console.Write("Сумка: ");
        for (int i = 0; i < bag.Length; i++) {
            Console.Write(bag[i] + " ");
        }
        Console.SetCursorPosition(userX, userY);
        Console.WriteLine('@');
        ConsoleKeyInfo charKey = Console.ReadKey();
        switch (charKey.Key) {
            case ConsoleKey.UpArrow:
                if (map[userX - 1, userY] != '#') {
                    userX--;
                }
                break;
            case ConsoleKey.DownArrow:
                if (map [userX+1,userY]!='#') {
                    userX++;
                }
                break;
            case ConsoleKey.LeftArrow:
                if (map[userX,userY-1]!='#') {
                    userY--;
                }
                break;
            case ConsoleKey.RightArrow:
                if (map[userX,userY+1]!='#') {
                    userY++;
                }
                break;
        } // switch
        if (map[userX,userY]=='X') {
            map[userX, userY] = 'o';
            char[] tempBag = new char[bag.Length+1];
            for (int i = 0; i < bag.Length; i++) {
                tempBag[i] = bag[i];
            }
            tempBag[tempBag.Length - 1] = 'X';
            bag = tempBag;
        }
        Console.Clear();
    } // while(true)
} // Main()

Пояснения к примеру 6.2
Символьный массив map - двумерный, объявлен
char[,] map = {//...};
В квадратных стоит только запятая, а резмеры не указаны. 
Компилятор узнает размеры по инциализации значениями - 
14 строками из 17 символов в каждой строке.

Перед выводом карты лабиринта скрывается текстовый 
курсор в консоли командой 
Console.CursorVisible = false;
Здесь обращение к свойству класса CursorVisible происходит 
без создания экземпляра класса Console. 
Такие классы, для обращения к полям которых не 
требуется создание объекта, называют статическими, 
их объялвение происходит с помощью ключевого 
слова static - спецификатора объвления класса.
static class Console {//...};

В начале программы задается положение персонажа 
при старте игры userX и userY.
Объявлен массив bag - рюкзак для хранения найденных 
кладов. Его начальная вместимость - 1 ячейка.
По мере добавления кладов в рюкзак его размер увеличивается.
Это происходит за счет одного из механизмов управления 
памятью на платформе .NET ("дот нет") - "сборщика мусора", 
от англ. garbage collector, который предотвращает 
одну из программных ошибок - "утечку памяти", от англ. 
memory leak. Объекты располагаются в специальной 
области памяти, которая называется "Куча", от англ. 
Heap. Распределением ячеек памяти из кучи занимается
ядро операционной системы по обращению к нему 
приложений. Если сборщик мусора обнаруживает в куче
объект, на который нет ни одной ссылки в переменных 
программы, то этот объект уничтожается, а ОС сообщается 
что занимаемые им ячейки свободны и могут быть 
заняты новыми объектами, возможно, из других программ. 
Куча - это общее пространство для всех процессов в системе. 

Игровой процесс происходит в бесконечном цикле
while (true) {}
