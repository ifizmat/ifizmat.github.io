Практическое занятие 9.
Тема: Прикладное программное обеспечение
Перечень заданий: Работа с пакетами компьютерной графики.

Практическое занятие 10.
Тема: Компьютерные сети
Перечень заданий: Определите IP-адрес локальных узлов сети. С помощью утилиты ping определите доступность двух узлов. Постройте модель сети двух компьютеров. Объедините в модели два компьютера в сеть с помощью хаба. Выполните тестирование сети, передачи пакетов. Создайте модель локальной сети с помощью коммутатора. Выполните в ней тестирование передачи пакетов.

Практическое занятие 11.
Тема: Компьютерные сети
Перечень заданий: Сетевая модель OSI. Операционные системы на ядре Linux. Выполните копирование большого количества файлов, несколько тысяч из одной сетевой папки в другую, проанализируйте скорость копирования. Сделайте выводы. 

Практическое занятие 12.
Тема: Компьютерные сети
Перечень заданий: Сетевая модель OSI. Особенности файловой системы. Принципы построения и функционирования. Архитектура операционной системы. Выполните копирование двух больших файлов, несколько гигабайт, с одного узла локальной сети на другой, подберите инструменты диагностики скорости копирования и сделайте выводы.

Практическое занятие 13.
Тема: Сервисы и ресурсы Интернет 
Перечень заданий: Выполните копирование папки с большим количеством файлов, несколько сотен из локальной папки в папку облачного хранилища. Определите время копирования, общий размер файлов, вычислите скорость обмена данными.

Практическое занятие 14.
Тема: Сервисы и ресурсы Интернет
Перечень заданий: Управление компьютерными сетями. Преимущества и недостатки операционной системы Linux в образовательном процессе средней школы. Анализ пакетов свободного программного обеспечения, рекомендуемых Министерством просвещения РФ. 
Создайте архив из нескольких тысяч небольших файлов в папке на локальном компьютере. Скопируйте файл в папку облачного хранилища. Определите скорость передачи данных. 

Практическое занятие 15.
Тема: Сервисы и ресурсы Интернет
Перечень заданий: Сетевые операционные системы. Безопасность и надежность информации и информационных потоков. Задачи безопасности. Создайте веб-документ, используя структурные теги. Добавьте в документ небольшой текст из энциклопедии и две иллюстрации. Загрузите веб-документ в браузер.

Практическое занятие 16.
Тема: Сервисы и ресурсы Интернет
Перечень заданий: Сервисы создания сайтов. Создайте сайт с помощью конструктора и выполните публикацию сайта. На одном из бесплатных хостингов опубликуйте веб-страницу, созданную локально. Разместите перекрестные ссылки на созданные сайты.
